# Use of Large Language Models

Large language models were used to assist with literature search, code
scaffolding, and drafting of the manuscripts and this repository.

All study design, code, experiments, and numerical results are the work of
the authors. The final text was written by the first author and edited with
LLM assistance. Every cited reference was checked against its primary source
before inclusion. No experimental number reported in the papers is
hand-entered: each is produced by the committed code and written to files
under `experiments/`, from which the manuscripts and figures are generated.

This statement is reproduced in the Acknowledgements of each manuscript.
